## 🇶 Streamlit을 사용해서 AI 모델을 웹 애플리케이션에 통합하려면 모델 로드, 사용자 입력, 결과 출력의 단계를 거쳐야합니다. 각각의 단계에 대해 설명해주세요.

Streamlit을 사용하여 AI 모델을 웹 애플리케이션에 통합하는 과정은 크게 **모델 로드 → 사용자 입력 → 결과 출력**의 3단계로 구성됨.

### 1) 모델 로드 (Model Loading)
- 애플리케이션 시작 시 AI 모델을 메모리에 로드
- 예: PyTorch, TensorFlow, HuggingFace 모델 로딩
- `@st.cache_resource`를 활용하여 재로딩 방지 및 성능 최적화

```python
@st.cache_resource
def load_model():
    model = ...
    return model
```

### 2) 사용자 입력 (User Input)
- 사용자로부터 텍스트, 이미지 등 입력을 받음
- Streamlit 위젯 사용 (`st.text_input`, `st.file_uploader` 등)

```python
user_input = st.text_input("질문을 입력하세요")
```

### 3) 결과 출력 (Result Output)
- 입력 데이터를 모델에 전달하여 추론 수행
- 결과를 화면에 출력 (`st.write`, `st.image` 등)

```python
if user_input:
    result = model(user_input)
    st.write(result)
```

## 🇶 FastAPI를 활용하여 AI 모델을 통합한 웹 API를 구현할 때, 기능별로 나눠서 구성하는 것이 바람직합니다. 전체적인 API 서버 코드 구조는 어떻게 구성되면 좋을지 자유롭게 작성해보세요.

FastAPI로 AI 모델을 통합할 때는 기능별로 모듈을 분리하여 유지보수성과 확장성을 확보하는 것이 중요함.

### 권장 프로젝트 구조

```
project/
│
├── app/
│   ├── main.py
│   ├── api/
│   │   └── v1/
│   │       └── endpoints/
│   │           └── inference.py
│   ├── core/
│   ├── models/
│   ├── services/
│   ├── utils/
│
├── model/
├── requirements.txt
└── Dockerfile
```

### 주요 구성 요소

#### 1) main.py
```python
from fastapi import FastAPI
from app.api.v1.endpoints import inference

app = FastAPI()
app.include_router(inference.router, prefix="/api/v1")
```

#### 2) Router
```python
from fastapi import APIRouter
from app.services.inference_service import predict

router = APIRouter()

@router.post("/predict")
def inference(data: dict):
    return predict(data)
```

#### 3) Service Layer
```python
def predict(data):
    result = model(data)
    return result
```
