# 📘 Weekly Paper — 딥러닝 모델 최적화 (ONNX, TensorRT, Quantization)

## 1. ONNX / TensorRT로 모델을 변환하는 이유

딥러닝 모델은 보통 PyTorch, TensorFlow 같은 프레임워크 환경에서 학습된다.  
하지만 실제 서비스에서는 추론 속도, 비용, 배포 환경이 훨씬 중요하다.

이때 사용하는 것이 ONNX, TensorRT 같은 최적화 포맷이다.

### ✅ ONNX (Open Neural Network Exchange)
- 다양한 프레임워크 간 모델 호환을 위한 표준 포맷
- PyTorch → TensorFlow → ONNX Runtime 등으로 이동 가능

👉 역할  
"모델을 범용적으로 사용할 수 있게 만드는 중간 표현"

---

### ✅ TensorRT
- NVIDIA GPU 기반 고속 추론 엔진
- 레이어 최적화, 연산 fusion, FP16/INT8 지원

👉 역할  
"GPU에서 최대 성능으로 실행되도록 최적화"

---

### 🔥 왜 변환해야 할까?

#### 1️⃣ 추론 속도 향상
- 불필요한 연산 제거
- 연산 fusion
- GPU 최적화

#### 2️⃣ 배포 환경 독립성
- 다양한 런타임에서 실행 가능
- 서버, 모바일, 엣지 디바이스 대응

#### 3️⃣ 비용 절감
- 더 적은 자원으로 동일 처리량 가능

---

### 💡 한 줄 정리
**학습용 모델 → 서비스용 모델로 변환하는 과정이 ONNX / TensorRT다**

---

## 2. PTQ vs QAT (양자화 기법 비교)

양자화(Quantization)는 모델의 연산 정밀도를 낮춰 속도와 효율을 높이는 기법이다.

### ✅ Post-Training Quantization (PTQ)
- 학습 완료된 모델에 후처리로 양자화 적용

👉 특징:
- 추가 학습 없음
- 구현 쉬움
- 정확도 손실 가능성 존재

---

### ✅ Quantization-Aware Training (QAT)
- 학습 과정에서 양자화 효과를 반영하며 학습

👉 특징:
- 양자화 오차를 학습 중 보정
- 정확도 유지 우수
- 구현 복잡

---

### 🔥 핵심 차이

| 구분 | PTQ | QAT |
|------|-----|-----|
| 적용 시점 | 학습 후 | 학습 중 |
| 난이도 | 쉬움 | 어려움 |
| 정확도 | 낮아질 수 있음 | 유지 우수 |
| 속도 | 빠름 | 느림 |

---

### 💡 선택 기준
- 빠른 적용 / 실험 → PTQ  
- 정확도 중요한 서비스 → QAT

---

### 🧠 한 줄 정리
**PTQ는 빠르게 줄이기, QAT는 정확도까지 고려한 최적화**

---

## 3. 모델 경량화 후 성능 검증 방법

양자화나 최적화는 단순히 빠르게 만드는 것이 아니라  
서비스 품질을 유지하는 것이 핵심이다.

### ✅ 1️⃣ 정확도 검증
- Accuracy, F1 Score, Top-k 등 비교
- 기존 모델 대비 성능 감소 범위 정의 (예: -1% 이내)

---

### ✅ 2️⃣ 추론 성능 측정
- Latency (응답 시간)
- Throughput (처리량)

---

### ✅ 3️⃣ 실제 데이터 테스트
- 테스트셋이 아닌 실제 서비스 데이터 활용
- edge case 확인

---

### ✅ 4️⃣ A/B 테스트
- 일부 사용자에게만 적용
- 성능 및 사용자 경험 비교

---

### ✅ 5️⃣ 안정성 검증
- 메모리 사용량
- CPU/GPU 사용률
- 장애 여부

---

### 🔥 체크리스트

1. 정확도 유지되는가?  
2. 속도 개선이 실제로 있는가?  
3. 실제 환경에서도 동일하게 동작하는가?  
4. 안정적으로 운영 가능한가?  

---

### 💡 한 줄 정리
**빠른 모델이 아니라, 문제없이 빠른 모델이 중요하다**

---

## 🚀 전체 흐름

Training Model  
→ ONNX 변환  
→ TensorRT 최적화  
→ Quantization  
→ 검증  
→ Production 배포  

---

## 🧠 최종 요약

- ONNX / TensorRT → 배포 및 성능 최적화 핵심  
- PTQ vs QAT → 속도 vs 정확도 트레이드오프  
- 검증 과정 → 서비스 품질 유지 핵심  

---

## ✍️ 마무리

딥러닝 모델의 성능은 학습에서 끝나지 않는다.  
배포 단계에서 진짜 성능이 결정된다.

실무에서는 "얼마나 잘 맞추는가"보다  
**"얼마나 빠르고 안정적으로 제공하는가"가 더 중요하다.**
